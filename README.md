# Basic Understanding of Assignments

## Program 1: Ball collisions (ball-ball and ball-wall)
I learnt and programmed a python code using numpy and pygame to:

1. Detect collisions using distance checks (balls) and boundary checks (walls).
2. Resolve ball-ball collisions using vector math: normal direction, relative velocity, and conservation of momentum and energy.
3. Fix overlaps after a collision so balls don't stick together.
4. Understand numerical issues such as time step size and tunneling

## Program 2: Cellular automata (sand, water, fire, wood, smoke)

Learnt and programmed a python code using numpy and pygame to:

1. Model a world as a grid where each cell follows local rules.
2. See how complex behavior (piles, flow, burning, rising smoke) emerges from those rules.
3. Handle update order (bottom up scanning) to avoid bias and overlapping moves.
4. Handle mouse input and real-time rendering in pygame.
5. Understanding texturing using random
